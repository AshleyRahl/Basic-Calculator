# Simple Python CLI Calculator

A clean and interactive Command-Line Interface (CLI) calculator built with Python. This script takes two numbers and a mathematical operator from the user, performs the calculation, and allows the user to specify exactly how many decimal places they want the final result rounded to.

## Features
* **Standard Arithmetic:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Custom Precision:** Dynamically rounds the final calculation to a user-defined number of decimal places.
* **Interactive CLI:** Simple prompts guide the user through the input process.

## How It Works
The script prompts you for three sequential inputs:
1. Two numeric values.
2. An operator symbol.
3. The desired decimal precision for the output.
